# Netflix Landing Page Clone

A Netflix-inspired streaming service landing page
built using HTML, CSS and Vanilla JavaScript.

## Features

- Responsive navbar
- Language selector
- Hero section
- Email validation
- Trending movie carousel
- FAQ accordion
- CTA section
- Responsive design
- Modular JavaScript
- Modular CSS

## Technologies

- HTML5
- CSS3
- JavaScript ES6
- ES6 Modules
